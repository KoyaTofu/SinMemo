# SinMemo

シンプルなメモ帳の Android アプリ。

アプリ開発の一連の流れ（要件定義 → 設計 → 実装 → テスト → 総合テスト → リリース）を学ぶために作った。書類とコードの作成は Claude Code が行い、決定・確認・マージ・実機での確認は開発者が行った。機能の作り込みより、流れを一通り経験することを優先している。

## 主な機能

| 機能 | 内容 |
|---|---|
| メモの一覧 | 保存したメモを更新日時の新しい順に並べる。各行に本文の 1 行目と更新日時を出す |
| メモの作成・編集・保存 | 一覧の「＋」で新規作成、行を押して編集、右上の「✓」で保存。本文は最大 10,000 文字。タイトル欄はない |
| メモの削除 | 編集画面のメニューから、確認のダイアログを経て削除する |
| 下書きの一時保存 | 書きかけのままアプリが裏に回り、システムに終了されても、戻ってきたときに書きかけごと開く |
| 設定 | テーマ（端末の設定に従う／ライト／ダーク）、文字サイズ（小／中／大）、バージョンの表示 |

作らないと決めたもの（検索、並べ替え、自動保存、共有、クラウド同期など）を含む一覧は [機能一覧](docs/要件/機能一覧.md)。

## 動作環境

- Android 10（API 29）以降
- 言語・UI: Kotlin、Jetpack Compose
- データの保存: Room（メモ）、DataStore（設定）。端末の中だけに保存し、外部への通信やバックアップはしない

## ビルドの仕方

Android Studio でこのフォルダを開き、▶（Run）で端末かエミュレータに入れる。コマンドで行う場合は次のとおり（Windows では `./gradlew` を `.\gradlew.bat` に読み替える）。

| 作業 | コマンド | 備考 |
|---|---|---|
| デバッグ版を作る | `./gradlew assembleDebug` | 出力は `app/build/outputs/apk/debug/`。デバッグ版は別のアプリ（`com.example.sinmemo.debug`）として入る |
| 自動テスト（PC） | `./gradlew testDebugUnitTest` | Robolectric で画面のテストも PC で動く。端末は要らない |
| リリース版を作る | `./gradlew assembleRelease` | 署名の情報がなければ未署名で作る（警告が出る） |

- Android SDK の場所は、Android Studio が作る `local.properties`（`sdk.dir`）か、環境変数 `ANDROID_HOME` で指定する
- リリース版の署名: 鍵のファイルの場所とパスワードを、環境変数かリポジトリ直下の `.env` に書く。項目名は [.env.example](.env.example)、書き方と鍵の作り方は [リリース 基本設計](docs/リリース/基本設計.md)。`.env` と鍵のファイルはリポジトリに入れない（`.gitignore` で除外済み）
