## 2. エミュレータ

Android 10（API 29）のエミュレータ（`SinMemo_API29`）。Claude が adb で操作して確かめる。

| ID | 確認すること | 手順 | 期待 |
|---|---|---|---|
| E-E-01 | US-01〜04 を通しで | ＋ → 入力 → ✓、メモを開いて直して ✓、⋮ →「削除」、← と D-02 | [基本設計](基本設計.md) 3.2 の表のとおり |
| E-E-02 | 画面回転で本文が消えない | 入力中に横向き → 縦向き | 本文が残る |
| E-E-03 | 戻るジェスチャー・戻るキーで D-02 | 変更ありで戻る操作 | D-02 が出る |
| E-E-04 | キーボードで入力欄が隠れない | 長い本文の末尾でキーボードを出す | 入力欄と文字数の行がキーボードの上にある（Android 10 では `adjustResize` が要る） |
| E-E-05 | 文字数の表示 | 9,500 文字以上の本文で開く | 「9,5xx/10,000文字」が入力欄の下に出る |

- 貼り付けは adb でクリップボードに入れられないため、エミュレータでは確かめない（E-U-39〜44 で確かめる）
