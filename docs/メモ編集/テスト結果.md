## 4. 7.4（#59）の端末での確認（2026-11-17、開発者と Claude）

OPPO CPH2099（Android 11、Gboard）、デバッグ版に `seed -OverLimit` で 1,001 件を入れて行った。手順は [テスト設計](テスト設計.md) 3.1、全体の結果は [総合テスト テスト結果](../総合テスト/テスト結果.md) 6.6。打ち足しの手間を減らすため、380・382 文字の貼り付け用のメモを DB に 2 件足した（その場限りのスクリプト）。

| ID | 結果 | 判定 |
|---|---|---|
| E-D-05 | 期待どおり（500 文字ほどの貼り付けは入らず「10,000文字を超えるため入力できません」、10,000 で赤、9,999 で絵文字は入らずメッセージ、破棄で元のまま） | ○ |
| E-D-06 | 上限に届いたところで変換中の文字がひらがなのまま確定し、変換できなかった（期待と違った）。落ちず、1 文字消すと「か」が入り、入力は続けられた。→ 仕様として受け入れ、[基本設計](基本設計.md) 5.3 とテスト設計の期待を直した（開発者の決定（2026-11-17）） | ○ |
| E-D-07 | 9,618 文字の貼り付けは入り、2 回目は入らずメッセージ。落ちず、破棄でメモは増えなかった | ○ |
| E-D-08 | 「✓」の二度押しで 1 件だけ、削除の二度押しでほかのメモは消えなかった（DB の件数でも確かめた） | ○ |
| E-D-09 | 10,050 文字のメモは増やせず、超えたまま「✓」で「10,000文字を超えるため保存できません」。9,997 文字に減らすと保存でき、開き直しても 9,997 文字。変えずに「←」で確認なしに戻った | ○ |
| K-5・K-6（K-6 は E-D-04） | 同じ版・同じ操作の E-D-05 の 1・2、E-D-06 で兼ねた（開発者の決定（2026-11-17）） | ○ |

- 3 章の「残り」の K-1〜K-6 は、2026-11-16 に済み（[総合テスト テスト結果](../総合テスト/テスト結果.md) 4 章）。7.4 の版でも 2026-11-17 に K-1〜K-4 をリリース版で確かめた
