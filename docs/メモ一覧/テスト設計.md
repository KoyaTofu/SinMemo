### 4.1 7.4 の端末での確認（#59）

開発者の端末（OPPO CPH2099、Android 11）で、開発者が手で操作する（この端末は adb のタップを受け付けない）。**デバッグ版（「SinMemo (debug)」）で行う**。時刻を変えて保存したメモの日時がずれるので、リリース版の自分のメモでは行わない。タイムゾーン・日付・時刻は端末の「設定」アプリから変える。終わったら必ず「自動設定」に戻す。

| ID | 確かめること | 出典 | 総合テストの ID |
|---|---|---|---|
| L-D-07 | 一覧を開いたままタイムゾーンを変えると、日時がすぐ変わる | #59 決定 11 | 5.6 |
| L-D-08 | 一覧を開いたまま日付を来年にすると、今年のメモに年が付く | #59 決定 11 | 5.6 |
| L-D-09 | 時計を戻してからメモを書き換えて保存すると、そのメモの行まで動く | #59 決定 2 | 5.6 |
| L-D-10 | 0 件の一覧で初めてメモを作る | #59 その他（異常系） | 5.6 |

※用語：分割画面：画面を上下に分けて、2 つのアプリを同時に出す機能。OPPO では最近使ったアプリの画面で、アプリの右上の「⋮」（または長押し）から「分割画面」を選ぶ。一覧を開いたまま「設定」アプリを操作するのに使う
※用語：タイムゾーン：地域ごとの時差の設定。日本は「東京」（世界時 +9 時間）

#### L-D-07 一覧を開いたままタイムゾーンを変える

準備: デバッグ版に、今年の日付のメモが 2 件以上ある（なければ「＋」で作る）。

| 3 | 「設定」アプリで「日付と時刻」を開き（OPPO では「その他の設定」の中）、「自動設定」（タイムゾーン）をオフにする | - |
| 4 | 「タイムゾーン」で「ロンドン」を選ぶ | 一覧の日時が**すぐに** 9 時間前になる（例: 「11/16 12:30」。3 月末〜10 月末の夏時間の間は 8 時間前） |
