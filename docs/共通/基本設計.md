## 2. 画面遷移の全体

画面は 3 つ（S-01 メモ一覧、S-02 メモ編集、S-03 設定）と、ダイアログ 4 つ（D-01〜D-04）。ダイアログは画面の上に重ねて出し、画面としては移らない。遷移の番号（T-01〜T-18）は [画面一覧](../要件/画面一覧.md) のもの。

```
[起動] ─────────────────────────▶ S-01 メモ一覧（開始画面。戻るとアプリ終了）
[システムに終了されたあと戻る] ──▶ 終了前の画面（S-02 なら書きかけ入り）

S-01 ─ メモを押す／「＋」──▶ S-02 メモ編集
S-02 ─ ✓ 保存／←（変更なし）／D-02「破棄」／D-01「削除」──▶ S-01
S-01 ─ ⋮「設定」──▶ S-03 設定 ─ ← ──▶ S-01
```

| 開き方 | 開く画面 |
|---|---|
| ホームのアイコンから最初から起動（アプリを消した・端末を再起動した後） | S-01 メモ一覧。書きかけは残らない |
| 裏に回っている間にシステムに終了され、そこから戻る | 終了前の画面。S-02 なら書きかけの入った編集画面（[下書き 基本設計](../下書き/基本設計.md)） |
| 画面の回転・ダークモードの切り替え | 同じ画面のまま。入力中の文字やスクロール位置も残る |

- **二度押し対策**: 画面を移る途中（前の画面がまだ操作を受け付けられる状態に戻っていない間）の操作は無視する。素早く 2 回押しても、同じ画面が 2 枚開いたり、戻りすぎたりしない
- 起動するときは、設定を読み終わるまでスプラッシュ（白地にアイコン）を出す（[設定 基本設計](../設定/基本設計.md)）
- 編集画面から一覧へ戻ったときの一覧の位置は [メモ一覧 基本設計](../メモ一覧/基本設計.md) の 5 章

## 3. 配色

操作できるモックアップ（[モックアップ検証](../記録/モックアップ検証.md)）の配色をアプリ全体で使う。ライトは白地に青、ダークは黒地に水色。端末の壁紙から色を取る機能（ダイナミックカラー）は使わない（決定事項 1）。

| 用途 | ライト | ダーク |
|---|---|---|
| 背景 | `#FFFFFF` | `#141518` |
| アプリバー | `#F3F4F7` | `#1E2024` |
| 文字 | `#1B1C1F` | `#E7E8EC` |
| 薄い文字（一覧の日時など） | `#5A5E6B` | `#A9ADB8` |
| 区切り線 | `#E3E5EA` | `#2E3138` |
| アクセント（「＋」ボタンなど） | `#2550C8` | `#9DB8FF` |
| アクセントの上の文字・アイコン | `#FFFFFF` | `#0F1E46` |
| メニュー・ダイアログ | `#FFFFFF` | `#272A31` |
| 危険（削除） | `#B3261E` | `#FF9A8F` |

- ライト・ダーク・端末の設定に従う、のどれにするかは設定画面で選ぶ。初期値はライト（[設定 基本設計](../設定/基本設計.md)）
- 画面を移る途中も背景はテーマの色のまま（ダークのときに白く光らない）

## 4. 文字サイズの段階

文字サイズは「小・中・大」の 3 段階。変わるのは一覧と編集画面の文字だけで、設定画面・アプリバー・ダイアログの文字は変わらない（[画面一覧](../要件/画面一覧.md) 決定事項 10）。値はモックアップの大きさ（px）をそのまま sp にした。

| 設定 | 一覧の 1 行目 | 一覧の日時 | 編集画面の本文 |
|---|---|---|---|
| 小 | 15sp | 12sp | 15sp |
| 中（初期値） | 17sp | 13sp | 17sp |
| 大 | 20sp | 15sp | 20sp |

- sp は端末の「フォントサイズ」の設定にも合わせて大きくなる単位
- 選び方は設定画面（D-04）。初期値は「中」（[画面一覧](../要件/画面一覧.md) 決定事項 9）

## 5. データがどこまで残るか

| データ | 保存先 | アプリを閉じる・最近使ったアプリから消す | 端末の再起動 | システムに終了されたあと戻る | アプリを消す（アンインストール） |
|---|---|---|---|---|---|
| メモ（本文・作成日時・更新日時） | 端末の DB | 残る | 残る | 残る | 消える。戻せない（バックアップしない。6.4） |
| 設定（テーマ・文字サイズ） | 端末の設定ファイル | 残る | 残る | 残る | 同上 |
| 書きかけ（保存していない本文） | 画面の状態（DB には書かない） | **残らない** | **残らない** | 残る（編集画面ごと戻る） | 残らない |
| 一覧のスクロール位置 | 画面の状態 | 残らない | 残らない | 残る | 残らない |

- メモは ✓ を押したときだけ DB に書く。自動保存はしない（[機能一覧](../要件/機能一覧.md) F-11 は対象外）
- 書きかけの詳しい動きは [下書き 基本設計](../下書き/基本設計.md)
- **自動バックアップ**: ~~メモの DB と設定のファイルは、Android 標準の自動バックアップ（Google のバックアップ・機種変更）の対象のまま~~ → **バックアップしない**（6.4。開発者の決定（2026-11-17））。Google のバックアップにも機種変更にも出さない
- 一覧のメモ件数の目安は 1,000 件（要件の非機能。1,000 件でも引っかからずにスクロールできることを実機で確かめた。[総合テスト結果](../総合テスト/テスト結果.md)）
- DB が壊れたときは、メモは消える（6.3。割り切り）

### 6.1 デバッグ版とリリース版は別のアプリ（#59 決定 3）

これまでデバッグ版とリリース版は同じアプリ（パッケージ名 `com.example.sinmemo`）で、署名の鍵が違うため、片方を入れるにはもう片方を消す（データも消える）必要があった（[リリース 基本設計](../リリース/基本設計.md) 5 章の 5）。7.4 からは**別のアプリとして並べて入れられる**ようにする。

| | リリース版 | デバッグ版 |
|---|---|---|
| パッケージ名（アプリの ID） | `com.example.sinmemo`（今のまま） | `com.example.sinmemo.debug` |
| ホーム画面・アプリ一覧の名前 | SinMemo | **SinMemo (debug)** |
| 一覧のアプリバーのタイトル | SinMemo | SinMemo（同じ。設計役の案: アプリの中の見た目は変えない） |
| 設定画面のバージョン | 1.0.0（[リリース 基本設計](../リリース/基本設計.md) 6.5。7.4 で 1.0.1 にしていたが、公開は 1.0.0 を始点にするため 1.0.0 / versionCode 1 に戻した（開発者の決定 2026-11-17）） | 1.0.0-debug（設計役の案） |
| メモ・設定のデータ | それぞれのアプリの中。**お互いに見えない** | 同左 |
| アイコン | 同じ | 同じ（名前で見分ける。設計役の案） |

- ユーザー（開発者）がふだん使うメモはリリース版に入れる。デバッグ版はテスト用のデータ（1,000 件など）を入れて試すのに使う
- デバッグ版を入れ直したり消したりしても、リリース版のメモは消えない
- 7.4 より前に入れたデバッグ版（パッケージ名 `com.example.sinmemo`）がある端末では、新しいデバッグ版は別のアプリとして入る。古いほうは消してよい（開発者の端末は 8.2 でリリース版に入れ替え済み）

### 6.2 DB や設定の保存が失敗したとき（#59 決定 1）

| 場面 | 動き |
|---|---|
| メモの保存（✓）で DB が失敗 | アプリは落ちない。「保存できませんでした」を出し、編集画面に残る。入力した本文はそのまま |
| メモの削除（D-01「削除」）で DB が失敗 | アプリは落ちない。「削除できませんでした」を出し、編集画面に残る（設計役の案: 決定 1 の文は保存のもの。削除には「削除できませんでした」を出す） |
| 設定の保存（D-03・D-04「OK」）が失敗 | アプリは落ちない。表示も元の値のまま（[設定 基本設計](../設定/基本設計.md) 6 章のとおり。メッセージは出さない） |

- DB の失敗は、端末の記憶装置がいっぱい、記憶装置の一時的なエラーなどで起きる。ふつうは起きない
- 詳しい動きは [メモ編集 基本設計](../メモ編集/基本設計.md) 5 章

### 6.3 DB が壊れたとき（#59 決定 6。割り切り）

- **割り切り: DB のファイルが壊れたら、メモは消える**。アプリは壊れたファイルを消して、空の DB で動き続ける（Android の DB の標準の動き。[共通 詳細設計](詳細設計.md) 4.4）。修復や警告の表示はしない
- 理由: 壊れるのは記憶装置の故障や電源断の途中など、まれな場合だけ。修復の仕組みは学ぶ目的に比べて大きすぎる。メモを守る手段は自動バックアップ（6.4）に任せる
- 総合テストで DB を外から入れ替えるスクリプト（`scripts/seed_memos.ps1`）が、アプリと違う DB の型を書くと、アプリが DB を開けずに落ちる。そのため**スクリプトに書いた DB の型の印（identityHash）がアプリと合っているかを自動テストで確かめる**（[共通 テスト設計](テスト設計.md) 2.4）

### 6.4 バックアップしない（#59 その他。開発者の決定（2026-11-17））

**メモと設定は、バックアップにも機種変更にも出さない**（開発者の決定（2026-11-17））。メモは個人の情報なので、端末の外へ出さない。

| データ | Google のバックアップ（クラウド） | 機種変更（端末から端末へ） |
|---|---|---|
| メモの DB（`sinmemo.db` と付属のファイル） | 預けない | 移さない |
| 設定のファイル（`settings.preferences_pb`） | 預けない | 移さない |
| それ以外（今はない。今後増えたものも） | 預けない | 移さない |

- そのため、**アプリを消す（アンインストール）と、メモと設定は戻せない**。機種変更しても新しい端末には移らない（ユーザーへの説明: 機種変更の前に、残したいメモは別の場所へ写しておく）
- デバッグ版も同じ設定。端末での確認は「移らないこと」を確かめる（[共通 テスト設計](テスト設計.md) 4.2 の C-D-05）
- 決定事項 3（バックアップの対象のまま）を変えた。設計役の案（DB と設定だけを含め、クラウドは画面ロックがあるときだけ）はやめた
- 作り方は [共通 詳細設計](詳細設計.md) 13.5
