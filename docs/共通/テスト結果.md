### 1.3 途中で起きた問題と対応
- 初回は 17 件すべてが `IllegalAccessException: ... module java.base does not export jdk.internal.access` で失敗した。Robolectric が SDK 36 の環境を作るときに JDK の内部 API を使うため
- `app/build.gradle.kts` の `testOptions.unitTests.all` で、テスト用 JVM に `--add-exports=java.base/jdk.internal.access=ALL-UNNAMED` を渡して解決した

## 2. 4.2 のエミュレータ確認で見つかった時刻の不具合（2026-11-12）

| 項目 | 内容 |
|---|---|
| 起きたこと | 起動直後に端末のタイムゾーンが変わり、一覧の日時が 5 時間ずれて表示された（エミュレータを `adb reboot` すると、タイムゾーンが変わることがある。[作業メモ](../記録/作業メモ.md)） |
| 原因 | 本番の `Clock` を `Clock.systemDefaultZone()` で作っていて、作った時点のタイムゾーンに固定されていた |
| 対応 | タイムゾーンを毎回読み直す `DeviceZoneClock` に変えた（[共通 詳細設計](詳細設計.md) の 9 章、決定事項 5） |
| 残り | 一覧を表示したままタイムゾーンが変わったときは、次の保存・削除か再起動まで古いまま（[メモ一覧 基本設計](../メモ一覧/基本設計.md) の 3.2 の制限） |
