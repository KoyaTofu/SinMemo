## 2. 各アプリの整理

### A. Fossify Notes（OSS）
- 想定ユーザー: 広告や余計な権限のない、シンプルなメモ帳がほしい人。プライバシー重視（README に「インターネット権限なしでオフライン動作」とある）
- 主なシナリオ: 買い物リストや住所、思いつきを素早く書く／ホーム画面ウィジェットからすぐ確認する
- 主要機能: 複数メモ（タブで切替）、テキストメモとチェックリスト、自動保存、検索、メモ単位の保護（ロック）、ウィジェット、色のカスタマイズ、エクスポート／インポート、自動バックアップ
- データ保存方式: 端末内 DB（Room。`notes`、`widgets` テーブル）。ファイルへのエクスポートも可
- 技術構成: Kotlin、Room、UI は XML レイアウト（主要画面で Compose の使用は見当たらなかった。依存定義には Compose 用の静的解析ルールあり）、minSdk 26 / targetSdk 36、GPL-3.0
- 情報源: https://github.com/FossifyOrg/Notes

### B. Markor（OSS）
- 想定ユーザー: Markdown や todo.txt などのプレーンテキストでメモを取りたい人、他の PC ツールや同期アプリとファイルを共有したい人
- 主なシナリオ: QuickNote にすぐ書き込む／To-Do ファイルを管理する／フォルダ（Notebook）にメモをファイルとして保存し、別の同期アプリで PC と共有する
- 主要機能: Markdown 等の構文ハイライトとプレビュー、HTML/PDF への変換・共有、自動保存と Undo/Redo、AES256 での暗号化、ダークテーマ、ディープリンク
- データ保存方式: 端末のファイルシステム上のテキストファイル（保存フォルダは変更可能）。同期機能は持たず外部の同期アプリに任せる
- 技術構成: Java（Kotlin ファイルなし）、minSdk 21 / compileSdk 35、Apache-2.0
- 情報源: https://github.com/gsantner/markor

### C. NotallyX（OSS）
- 想定ユーザー: Google Keep のようなカード型メモを、オフライン・オープンソースで使いたい人
- 主なシナリオ: メモやタスクリストを作り、色・ピン・ラベルで整理する／リマインダーで通知を受ける／他アプリ（Keep、Evernote）から移行する
- 主要機能: リッチテキスト、サブタスク付きタスクリスト、リマインダー、ファイル・画像・音声の添付、並べ替え、色・ピン・ラベル、Undo/Redo、ウィジェット、生体認証／PIN ロック、自動バックアップ、インポート、リスト／グリッド表示
- データ保存方式: 端末内 DB（Room。暗号化に SQLCipher を使用）。バックアップはファイルに出力
- 技術構成: Kotlin、Room、SQLCipher、WorkManager、Biometric、UI は XML（ViewBinding）、AGP 9.4.1 / Kotlin 2.4.20、minSdk 24 / targetSdk 36、GPL-3.0
- 情報源: https://github.com/Crustack/NotallyX （派生元: https://github.com/OmGodse/Notally ）

### D. Omni-Notes（OSS）
- 想定ユーザー: 古い端末でも動く、シンプルな見た目と多機能を両立したメモを求める人（README より）
- 主なシナリオ: メモを作成・編集・アーカイブ・ゴミ箱へ移動する／検索・共有する／カテゴリやタグで分類する
- 主要機能: アーカイブ・ゴミ箱、検索・共有・結合、インポート／エクスポート、画像・音声・ファイル添付、タグとカテゴリ、To-Do リスト、手書きスケッチ、ウィジェット、多言語対応
- データ保存方式: 端末内 DB（SQLiteOpenHelper を直接使用）。同期は「今後の予定」として README に記載
- 技術構成: Java 中心（一部 Kotlin）、minSdk 24 / targetSdk 36、GPL-3.0
- 情報源: https://github.com/federicoiosue/Omni-Notes

### E. Google Keep（市販）
- 想定ユーザー: Google アカウントを持つ一般ユーザー全般。思いついたことをすぐ残したい人
- 主なシナリオ: メモやチェックリストを素早く作る／ラベル・色・ピン留めで整理する／時刻や場所でリマインドする／PC（Web）とスマホで同じメモを見る
- 主要機能: メモ、チェックリスト、手描き、ピン留め・色・アーカイブ、ラベル、リマインダー（時刻・場所・繰り返し）、共有、検索
- データ保存方式: Google アカウントのクラウドに保存し、端末間で同期。オフラインでも使える
- 技術構成: 非公開
- 情報源:
  - https://support.google.com/keep/topic/3316156?hl=en
  - https://support.google.com/keep/answer/2888068?hl=en-GB
  - https://workspace.google.co.nz/products/keep/

### F. Samsung Notes（Galaxy プリインストール）
- 想定ユーザー: Galaxy 端末のユーザー、特に S ペンで手書きしたい人
- 主なシナリオ: 手書きや文字でノートを取る／手書きを文字に変換する／PDF に書き込む／ウィジェットから確認する
- 主要機能: 手書き・テキスト変換、タグ、PDF・Word・画像などの形式で共有、ウィジェット
- データ保存方式: 端末内に保存し、Samsung Cloud と同期可能。OneNote との同期は終了した（Samsung のサポートページおよび報道より）
- 技術構成: 非公開
- 情報源:
  - https://www.samsung.com/us/support/owners/app/samsung-notes
  - https://www.samsung.com/us/support/answer/ANS10001384/
  - https://www.samsung.com/us/support/troubleshoot/TSG10013306/
  - https://www.androidauthority.com/samsung-notes-sync-with-onenote-ending-3662031/

### G. Microsoft OneNote（市販）
- 想定ユーザー: Microsoft 365 / OneDrive を使う人、仕事や学習で情報を体系的に整理したい人
- 主なシナリオ: ノートブック→セクション→ページの階層で整理する／PC とスマホで同じノートを見る
- 主要機能: ノートブック・セクション・ページの作成、同期（Wi-Fi のみの設定も可）、各種コンテンツの貼り付け
- データ保存方式: OneDrive（個人）や SharePoint（組織）のクラウドに保存し同期
- 技術構成: 非公開
- 情報源:
  - https://support.microsoft.com/en-us/office/key-features-of-onenote-for-android-f81711c7-12a8-4a90-8fb2-63445b83fa1e
  - https://support.microsoft.com/en-au/office/create-sections-pages-or-notebooks-in-onenote-for-android-c576539a-08ef-4c93-acdf-8120c3931633

## 4. ユーザーシナリオの共通点と相違点

### 共通点
- **素早く書いて、後で見返す**: どのアプリも「起動→すぐ書く→自動または簡単に保存→一覧から開く」が中心
- **一覧から選んで編集・削除**: メモが複数あり、一覧画面と編集画面の2画面構成が基本
- **チェックリスト（買い物・ToDo）**: ほとんどのアプリが、通常メモとは別にチェックリストを用意している
- **データを失わない**: 自動保存、バックアップ、エクスポートのいずれかを必ず備えている

### 相違点
- **保存先**: 端末内のみ（OSS 多数）／ファイルとして保存（Markor）／クラウド同期（市販）。OSS はプライバシー・オフラインを売りにし、市販はアカウント連携・複数端末を売りにしている
- **整理のしかた**: なし（Fossify）／ラベル・色・ピン（Keep、NotallyX）／カテゴリ・タグ（Omni-Notes）／階層（OneNote）／フォルダ（Markor）
- **入力形式**: プレーンテキスト中心／Markdown／リッチテキスト／手書き
- **付加機能**: リマインダー、添付、ロック、ウィジェット等はアプリごとに差が大きい

## 5. SinMemo で最低限必要な機能

学習目的（開発の一連の流れを理解する）のため、全アプリに共通する機能に絞る。

| 区分 | 機能 | 根拠 |
|---|---|---|
| 必須 | メモの新規作成 | 全アプリ共通 |
| 必須 | メモの一覧表示 | 全アプリ共通 |
| 必須 | メモの編集・保存 | 全アプリ共通 |
| 必須 | メモの削除 | 全アプリ共通 |
| 必須 | 端末内への永続保存（アプリを閉じても残る）。保存方式は Room（SQLite） | 全アプリ共通。類似 OSS でも Room／SQLite が主流 |
| 対象外 | 自動保存、検索 | 類似アプリにはあるが、SinMemo では不要と判断 |
| 対象外 | チェックリスト | 実装量が増えるため |
| 対象外 | 並べ替えの切替（更新日時順など） | NotallyX 等。並び順は更新日時の新しい順で固定にした（[機能一覧](../要件/機能一覧.md) F-09・決定事項 3） |
| 対象外 | クラウド同期、添付、リマインダー、ロック、手書き、ウィジェット | 市販や多機能 OSS の差別化要素。学習の範囲としては大きい |
