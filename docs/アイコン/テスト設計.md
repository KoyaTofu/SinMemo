ID の付け方: アイコンは接頭字 `IC`。自動テスト `IC-U-01`、ビルドの確認 `IC-B-01`、エミュレータ `IC-E-01`、実機 `IC-D-01`。

## 1. 自動テスト（PC、Robolectric）

### 1.1 ビルドの確認（PC）

| ID | 確認すること | コマンド |
|---|---|---|
| IC-B-01 | デバッグ版・リリース版のビルドが通る | `.\gradlew.bat assembleDebug assembleRelease` |
| IC-B-02 | APK のアプリのアイコンが `ic_launcher` になっている | `aapt2 dump badging`（デバッグ版）、`aapt2 dump resources`（リリース版。リソース名が短く縮められるため） |
| IC-B-03 | 起動用テーマのスプラッシュのアイコンが `ic_launcher_foreground` | `aapt2 dump resources` |
| IC-B-04 | lint にアイコンに関する指摘がない | `.\gradlew.bat lintDebug` |

### 1.2 単体テスト（`LauncherIconTest`、Robolectric）

コマンド: `.\gradlew.bat testDebugUnitTest --rerun`

| ID | テスト | 確認すること |
|---|---|---|
| IC-U-01 | manifest_usesLauncherIcon | アプリのアイコンが `R.mipmap.ic_launcher` |
| IC-U-02 | launcherIcon_isAdaptive_withDesignedLayers | アイコンが adaptive icon で、背景が `#F3F4F7`、前景と単色版がある（Android 13 として読む） |
| IC-U-03 | vectorDrawables_canBeInflated | 前景・単色版のベクター画像（だ円の弧を含む）が読めて、大きさが 108dp |
| IC-U-04 | splashTheme_showsForegroundIcon | 起動用テーマのスプラッシュのアイコンが `ic_launcher_foreground` |

- 壊す確認: 単色版を外す・スプラッシュのアイコンを外す・マニフェストの `android:icon` を外す、を 1 つずつ入れて失敗することを確かめる

## 2. エミュレータ

エミュレータ `SinMemo_API29`（Android 10）。

| ID | 確認すること |
|---|---|
| IC-E-01 | アプリ一覧（丸）で用紙と S が切れずに出る。ほかのアプリと同じ大きさ |
| IC-E-02 | アイコンの形を変えても（開発者向けの `com.android.theme.icon.*`: 四角・しずく・スクワークル・角丸）、用紙と S が切れない |
| IC-E-03 | 最近使ったアプリ（暗い壁紙の上）で出る |
| IC-E-04 | スプラッシュで、白の上に用紙と S が出る（Android 標準のアイコンでない） |
| IC-E-05 | 端末をダークにしたときのアプリ一覧で見える |

- エミュレータは Android 10 なので、テーマアイコン（Android 13 以降）は確かめられない。実機（3 章）で見る

## 3. 実機

開発者の端末のランチャーでの見え方。各工程の実機確認は総合テスト（7.2）にまとめた（[スケジュール](../記録/スケジュール.md) 決定事項 7）。

| ID | 確認すること | 総合テストでの番号 |
|---|---|---|
| IC-D-01 | ホーム画面・アプリ一覧でアイコンが切れずに出る（端末のランチャーの形） | R-8 |
| IC-D-02 | Android 13 以降: 壁紙とスタイル →「テーマアイコン」をオンにすると、SinMemo も単色になる | R-9 |
| IC-D-03 | 端末をダークにしたときのアプリ一覧での見え方 | R-10 |
