## 2. 絵柄（決定事項 1）

![アイコンの見本](../icon/ic_launcher_preview.svg)

左から、白いホーム画面、ダークのホーム画面、テーマアイコン（単色版。色は壁紙に合わせて端末が決める。図の色は例）。

| 部品 | 形 | 色 |
|---|---|---|
| 背景 | 全面 | 薄い灰 `#F3F4F7`（ライトのアプリバーと同じ色。[共通 基本設計](../共通/基本設計.md) の配色の `surfaceContainer`） |
| 用紙 | 右上の角を折った縦長の紙 | 中は白 `#FFFFFF`、縁取りは青 `#2550C8`（`primary`。一覧の ＋ ボタンと同じ） |
| 折り目 | 右上の三角の線 | 青 `#2550C8` |
| 文字 | 用紙の中に「S」（SinMemo の頭文字） | 青 `#2550C8` |

- 「S」はフォントを使わず、線（2 つのだ円の弧）で描く。アイコンはベクター画像で、文字の形を入れられないため
- 背景を白でなく薄い灰にしたのは、白い用紙の形が背景と分かれて見えるようにするため

## 3. 見え方

| 場所 | 見え方 |
|---|---|
| ホーム画面・アプリ一覧 | 端末のランチャーの形（丸・角丸・四角・しずくなど）で切り抜かれる。どの形でも用紙と S は切れない |
| 最近使ったアプリ | アプリの上に同じアイコンが出る |
| テーマアイコン（Android 13 以降でユーザーがオンにしたとき） | 単色版。用紙・折り目・S の線だけを、壁紙に合わせた色で出す |
| スプラッシュ | 4 章 |

## 4. スプラッシュのアイコン（決定事項 3）

- アイコンの前景（用紙と S）だけを、スプラッシュの白い背景の上に出す。背景の灰の円は付けない
- 用紙の青い縁取りがあるので、白の上でも形が分かる
- スプラッシュの背景は [設定 基本設計](../設定/基本設計.md) 5 章のとおり白で固定（変えない）
- アイコンを作る前は、スプラッシュには Android 標準のアイコンが出ていた → このアイコンに替えた

## 決定事項（2026-11-15）
