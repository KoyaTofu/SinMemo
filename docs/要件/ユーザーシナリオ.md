## シナリオ詳細

書き方（決定事項 8）
- 1 行に 1 つの操作。「ユーザーの操作」と「アプリの動き」を列に分ける
- 画面の部品は「」で囲む（例: 「＋」ボタン）。専門用語には、表のすぐ下に「※」で解説を付ける
- 例外は同じ表に「例外 1」「例外 2」と書く。アプリの動きで書くことがないときは「-」

画面の部品（どのシナリオでも同じ）

| 部品 | 場所 | 働き |
|---|---|---|
| 「＋」ボタン（FAB） | 一覧の右下 | 新しいメモの編集画面を開く |
| 「⋮（メニュー）」ボタン | 一覧の右上 | 「設定」を選べるメニューを出す |
| 「←（戻る）」ボタン | 編集画面の左上 | 一覧に戻る。端末の戻る操作（画面の端からのスワイプ・戻るキー）も同じ |
| 「✓（保存）」ボタン | 編集画面の右上 | 保存して一覧に戻る |
| 「⋮（メニュー）」ボタン | 編集画面の右上（保存済みのメモだけ） | 「削除」を選べるメニューを出す |

※FAB：画面右下に浮いている丸いボタン（Floating Action Button）。その画面で一番よく使う操作を置く

### US-01 思いついたことをメモする
| No | ユーザーの操作 | アプリの動き |
|---|---|---|
| 1 | アプリを起動する | メモ一覧画面が出る |
| 2 | 「＋」ボタンを押す | 空の編集画面が開き、キーボードが出る |
| 3 | 本文を書く（タイトル欄はない） | - |
| 4 | 「✓（保存）」ボタンを押す | メモを保存して一覧に戻る。一覧は先頭に戻り、書いたメモが一番上に出る |
| 例外 1 | 本文が空のまま「✓（保存）」ボタンを押す | 押せない（ボタンが薄い色） |
| 例外 2 | 書いたあと、「←（戻る）」ボタンを押す | 「変更を破棄しますか？」と確認が出る |
| 例外 2-1 | 確認で「破棄」ボタンを押す | 保存せずに一覧に戻る |
| 例外 2-2 | 確認で「キャンセル」ボタンを押す | 編集画面のまま。書いた中身も残る |

### US-02 書いたメモを後で見返す
| No | ユーザーの操作 | アプリの動き |
|---|---|---|
| 1 | アプリを起動する | 一覧に、各メモの本文の 1 行目と更新日時が、更新日時の新しい順に出る |
| 2 | 見たいメモを押す | 編集画面が開き、全文が出る |

### US-03 メモを書き直す
| No | ユーザーの操作 | アプリの動き |
|---|---|---|
| 1 | 一覧で、直したいメモを押す | 編集画面が開き、全文が出る |
| 2 | 本文を直す | - |
| 3 | 「✓（保存）」ボタンを押す | 保存して一覧に戻る。直したメモが一番上に移り、更新日時が今になる |
| 例外 1 | 何も変えずに「✓（保存）」ボタンを押す | 保存せずに一覧に戻る（更新日時は変わらない） |
| 例外 2 | 直している途中で画面を回す | 書いた中身は消えない |
| 例外 3 | 直したあと、「←（戻る）」ボタンを押す | US-01 の例外 2 と同じ |

### US-04 不要になったメモを消す
| No | ユーザーの操作 | アプリの動き |
|---|---|---|
| 1 | 一覧で、消したいメモを押す | 編集画面が開く |
| 2 | 「⋮（メニュー）」ボタンを押す | 「削除」が出る |
| 3 | 「削除」を押す | 「このメモを削除しますか？」と確認が出る |
| 4 | 確認で「削除」ボタンを押す | メモを消して一覧に戻る |
| 例外 1 | 確認で「キャンセル」ボタンを押す | 編集画面のまま。メモは消えない |

### US-05 アプリを閉じても残っている
| No | ユーザーの操作 | アプリの動き |
|---|---|---|
| 1 | メモを保存する（US-01） | - |
| 2 | アプリを終わらせる（最近使ったアプリの一覧から消す、または端末を再起動する） | - |
| 3 | アプリをもう一度起動する | 保存したメモが一覧に出る |

### US-06 書きかけの内容が戻ってくる
| No | ユーザーの操作 | アプリの動き |
|---|---|---|
| 1 | メモを書いている途中（保存前）に電話がかかってきて、アプリが裏に回る | 書きかけを下書きとして一時保存する |
| 2 | （ユーザーは何もしない） | 端末のメモリが足りなくなり、システムがアプリを終わらせることがある |
| 3 | 電話のあと、最近使ったアプリの一覧か、ホーム画面のアイコンからアプリに戻る | 書きかけの入った編集画面に戻る |
| 4 | 「✓（保存）」ボタンで保存する、または「←（戻る）」ボタン →「破棄」ボタンで捨てる | どちらでも下書きは消える |
| 例外 1 | 書きかけのまま、アプリを最近使ったアプリの一覧から消す（または端末を再起動する）。そのあと起動する | 一覧が開く。書きかけは残らない（決定事項 7） |

- 下書きは 1 件だけ持つ
- 書きかけを戻したことは画面に出さない（[モックアップ検証](../記録/モックアップ検証.md) 論点 4）
- 詳しい動きは [下書き 基本設計](../下書き/基本設計.md)

## 対象外としたシナリオ
- 多くのメモの中からキーワードで探す（検索）
- 複数の端末・PC で同じメモを見る（クラウド同期）
- 写真を添付する、手書きする、チェックリストを使う
- 指定時刻に通知してもらう（リマインダー）
- 他アプリへ本文を送る（共有）
- 初回起動時（メモ 0 件）に案内文を見る（機能一覧 決定事項 2 で不要と決定。0 件のときは空の一覧と「＋」ボタンのみ）
