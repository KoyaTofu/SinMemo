## 表示形式

| 項目 | 形式 | 例 |
|---|---|---|
| 更新日時（今年） | 月/日 時:分（年を省略）。月・日・時・分は 0 で埋めて 2 桁にする | `11/12 14:30`、`01/05 09:03` |
| 更新日時（去年以前） | 年/月/日 時:分（同じく 0 で埋める） | `2025/11/12 14:30`、`2025/01/05 09:03` |
| 本文 1 行目 | 1 行に収まらない分は「…」で省略。1 行目が空白のみの場合は最初の空でない行を表示 | `牛乳、卵、パン…` |

※ 1 行目が空白のみの場合の扱いは、決定事項から導いた案。[メモ一覧 基本設計](../メモ一覧/基本設計.md) でこのとおりに決めた（すべての行が空白だけなら何も表示しない）。

## データ項目

| 項目 | 型 | 必須 | 説明 |
|---|---|---|---|
| id | Long（自動採番） | ○ | メモの識別子 |
| body | String（最大 10,000 文字） | ○ | 本文。空は不可 |
| createdAt | Long（エポックミリ秒） | ○ | 作成日時 |
| updatedAt | Long（エポックミリ秒） | ○ | 更新日時。一覧の並び順に使う |

下書き（F-07）は DB に保存しない。編集画面の状態（SavedStateHandle）に本文を入れる。詳細は [下書き 基本設計](../下書き/基本設計.md)・[下書き 詳細設計](../下書き/詳細設計.md)。DB の作りは [共通 詳細設計](../共通/詳細設計.md)。

## 決定事項（2026-11-12）
| No | 論点 | 決定 |
|---|---|---|
| 1 | 必須の範囲 | F-01〜F-07（画面一覧で F-16〜F-19 を追加） |
| 2 | 空状態の案内 | 表示しない |
| 3 | 並び順 | 更新日時の新しい順で固定 |
| 4 | 日時の表示形式 | 今年は年を省略（`11/12 14:30`）、去年以前は年も表示 |
| 5 | 本文の最大文字数 | 制限する（10,000 文字。選択肢の例示値を採用） |
| 6 | 10,000 文字を超えるとき | それ以上入力できない。貼り付け後に 10,000 文字を超える場合は貼り付けを丸ごと取り消し、「10,000文字を超えるため貼り付けられません」を表示する。→ 当初（画面一覧で決定）は「超える分を切り詰めて貼り付ける」だったが、今の形に変えた（理由: 一部だけ入ると気づきにくいため。2026-11-12 [メモ編集 基本設計](../メモ編集/基本設計.md) の決定事項「上限を超える貼り付け」で決定） |
| 7 | 設定の保存先 | DataStore。→ 要件の時点では「DataStore を想定（設計で確定）」としていた。2026-11-12 [設定 詳細設計](../設定/詳細設計.md) で確定 |
| - | タイトル | 持たない（要件定義書 決定事項 3） |
| - | 削除方式 | 確認ダイアログ（要件定義書 決定事項 5） |
| - | 共有 | 対象外（ユーザーシナリオ 決定事項 6） |
