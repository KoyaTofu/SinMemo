- 関連書類: [要件定義書](要件定義書.md)、[ユーザーシナリオ](ユーザーシナリオ.md)、[機能一覧](機能一覧.md)、[モックアップ検証](../記録/モックアップ検証.md)。各画面の設計は「設計の場所」の列のフォルダ

## 画面一覧

| 画面ID | 画面名 | 概要 | 主な表示項目 | 主な操作 | 関連機能 | 設計の場所 |
|---|---|---|---|---|---|---|
| S-01 | メモ一覧画面 | 起動時に表示。保存済みメモの一覧 | アプリバー（「SinMemo」、メニュー ⋮）、各メモの本文 1 行目と更新日時（更新日時の新しい順）、FAB「＋」 | メモを押す→S-02／「＋」→S-02（新規）／⋮「設定」→S-03 | F-01, F-02 | [メモ一覧](../メモ一覧/基本設計.md) |
| S-02 | メモ編集画面 | メモの表示・編集・保存・削除 | アプリバー（戻る ←、保存 ✓、メニュー ⋮）、本文入力欄 | 入力／✓ で保存して S-01 へ／← で戻る（未保存なら D-02）／⋮「削除」→D-01 | F-03, F-04, F-05, F-07 | [メモ編集](../メモ編集/基本設計.md)、[下書き](../下書き/基本設計.md) |

| D-01 | 削除確認ダイアログ | 削除の確認 | 「このメモを削除しますか？」 | 削除／キャンセル | F-05 | [メモ編集](../メモ編集/基本設計.md) |
| D-02 | 破棄確認ダイアログ | 未保存のまま戻るときの確認 | 「変更を破棄しますか？」（新規作成時も同じ文言） | 破棄／キャンセル | F-04 | [メモ編集](../メモ編集/基本設計.md) |
| D-03 | テーマ選択ダイアログ | テーマを選ぶ | 端末の設定に従う（端末のライト／ダークに追従）／ライト／ダーク | 選択して OK／キャンセル（決定事項 12） | F-17 | [設定](../設定/基本設計.md) |

起動時のスプラッシュ画面と、ランチャーアイコンは要件の時点では画面一覧に入れていない。スプラッシュは [設定 基本設計](../設定/基本設計.md)（設定を読み終わるまでの画面）、アイコンは [アイコン 基本設計](../アイコン/基本設計.md) を見る。

## 画面のラフ

操作できるモックアップを作成した（[モックアップ検証](../記録/モックアップ検証.md)）。以下のテキスト図は当初のラフ。

### S-01 メモ一覧画面
```
┌─────────────────────────┐
│ SinMemo              ⋮ │ ← ⋮ を押すと「設定」
├─────────────────────────┤
│ 牛乳、卵、パン…        │
│ 11/12 14:30             │
├─────────────────────────┤
│ 打ち合わせメモ          │
│ 11/10 09:15             │
├─────────────────────────┤
│ 旅行の持ち物            │
│ 2025/12/28 21:04        │ ← 去年以前は年も表示
├─────────────────────────┤
│                         │
│                         │
│                   ┌───┐ │
│                   │ ＋│ │ ← 新規作成
│                   └───┘ │
└─────────────────────────┘
```
- メモが 0 件のときは、一覧部分が空で「＋」だけが表示される（案内文は出さない）
- 文字の大きさは S-03 の文字サイズ設定に従う

### S-02 メモ編集画面
```
┌─────────────────────────┐
│ ←              ✓    ⋮ │ ← ✓=保存、⋮ を押すと「削除」
├─────────────────────────┤
│ 牛乳、卵、パン          │
│ 洗剤                    │
│ █                       │ ← 本文入力欄（画面いっぱい）
│                         │
│                         │
│                         │
│                         │
├─────────────────────────┤
│      （キーボード）     │
└─────────────────────────┘
```
- 本文が空のときは ✓ を押せない（グレー表示）
- 本文は 10,000 文字まで。それ以上は入力できない。貼り付け後に 10,000 文字を超える場合は貼り付けを取り消し、「10,000文字を超えるため貼り付けられません」と表示する（決定事項 2）
- 9,500 文字以上になったら、入力欄の下の別の行に（右寄せで）「9,688/10,000文字」の形で文字数を表示する（[メモ編集 基本設計](../メモ編集/基本設計.md) で決定）
- 新規作成時はキーボードを自動で出す。既存メモは本文を押したときに出す（[メモ編集 基本設計](../メモ編集/基本設計.md) で決定）
- 新規作成時（一度も保存していないメモ）は「削除」メニューを出さない
- 文字サイズは S-03 の設定に従う

### S-03 設定画面
```
┌─────────────────────────┐
│ ←  設定                 │
├─────────────────────────┤
│ テーマ                  │
│ ライト                  │ ← 押すと D-03（初期値: ライト）
├─────────────────────────┤
│ 文字サイズ              │
│ 中                      │ ← 押すと D-04（初期値: 中）
├─────────────────────────┤
│ バージョン              │
│ 1.0.0                   │ ← 表示のみ
└─────────────────────────┘
```
- バージョンの値は [リリース 基本設計](../リリース/基本設計.md) で決めた versionName（1.0.0）。ラフを作った時点では 0.1.0 と書いていた

┌───────────────────────┐   ┌───────────────────────┐
│ このメモを削除します  │   │ 変更を破棄しますか？  │
│ か？                  │   │                       │
│                       │   │                       │
│   キャンセル   削除   │   │  キャンセル   破棄    │
└───────────────────────┘   └───────────────────────┘

D-03 テーマ                    D-04 文字サイズ
┌───────────────────────┐   ┌───────────────────────┐
│ テーマ                │   │ 文字サイズ            │
│ ○ 端末の設定に従う   │   │ ○ 小                 │
│ ◉ ライト             │   │ ◉ 中                 │
│ ○ ダーク             │   │ ○ 大                 │

- D-03・D-04 は、項目を選んで「OK」を押したときに設定を反映して閉じる。「キャンセル」では何も変えない（決定事項 12）

## 画面遷移

### 遷移図（テキスト）
```
[起動] ──▶ S-01 メモ一覧
[システムに終了されたあと戻る] ──▶ 終了前の画面（S-02 なら書きかけ入り）
              │  ▲
   メモ/＋    │  │ ✓保存 ／ ←（変更なし）／ D-02「破棄」
              ▼  │
           S-02 メモ編集
              │
              ├─ ←（未保存の変更あり）─▶ D-02 ─「キャンセル」─▶ S-02
              │
              └─ ⋮「削除」─▶ D-01 ─「削除」─▶ S-01
                                 └「キャンセル」─▶ S-02

S-01 ─ ⋮「設定」─▶ S-03 設定 ─ ← ─▶ S-01
                     ├─ テーマ ─▶ D-03 ─▶ S-03
                     └─ 文字サイズ ─▶ D-04 ─▶ S-03
```

| T-05 | S-01 | ⋮「設定」 | S-03 | |

## 実装方針
- 画面遷移は Navigation Compose を使う
- Activity は 1 つ（`MainActivity`）で、画面は Composable で切り替える
- 作りの詳細は [共通 詳細設計](../共通/詳細設計.md)

## 決定事項（2026-11-12）
| No | 論点 | 決定 |
|---|---|---|
| 1 | 画面構成 | 一覧・編集・設定の 3 画面＋ダイアログ 4 つ |
| 2 | 文字数上限を超えるとき | それ以上入力できない。超える貼り付けは丸ごと取り消してメッセージを表示する。→ 当初は「貼り付けは切り詰め」だったが、今の形に変えた（理由: 一部だけ入ると気づきにくいため。2026-11-12 [メモ編集 基本設計](../メモ編集/基本設計.md) の決定事項「上限を超える貼り付け」で決定。[機能一覧](機能一覧.md) 決定事項 6 と同じ） |
| 3 | 保存ボタンの位置 | 編集画面のアプリバー右上（✓） |
| 4 | 保存後の動き | 一覧に戻る |
| 5 | 設定画面 | 作る。項目はテーマ切替・文字サイズ・バージョン表示 |
| 6 | 設定画面の入口 | 一覧画面のアプリバー右上メニュー（⋮） |
| 7 | 画面遷移の実装 | Navigation Compose を使う |
| 8 | 画面ラフ | 今作る（このファイルのテキスト図） |
| 9 | テーマ・文字サイズの初期値 | テーマ「ライト」、文字サイズ「中」 |
| 10 | 文字サイズの反映先 | 一覧画面と編集画面の両方 |
| 11 | 新規作成時の「削除」メニュー | 出さない |
| 12 | D-03・D-04 の反映のしかた | 選んで「OK」を押したときに保存・反映する。ボタンは「キャンセル」「OK」。→ 当初の案は「項目を選んだ時点で反映して閉じる」（操作は「選択／キャンセル」）だったが、今の形に変えた（理由: 選び直しができるように。2026-11-12 [設定 基本設計](../設定/基本設計.md) で決定） |
| 13 | システムに終了されたあと戻ったとき（T-02） | 終了前の画面に戻る（S-02 なら書きかけ入り）。→ 当初は「一覧から自動で S-02 を開く」だったが、今の形に変えた（理由: 開発者の指摘。2026-11-12 [下書き 基本設計](../下書き/基本設計.md) で決定。[要件定義書](要件定義書.md) 決定事項 11 と同じ） |
| - | 削除の確認・場所 | 確認ダイアログ、編集画面のメニューのみ（要件定義書 決定事項 5、ユーザーシナリオ 決定事項 4） |
