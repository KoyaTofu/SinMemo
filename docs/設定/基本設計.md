| 部品 | 内容 |

- 今の値のまま「OK」を押した場合も、そのまま閉じる（値は変わらない）

## 3. 操作ごとの動き

| 操作 | 動き | 画面一覧の遷移 |
|---|---|---|
| S-03「テーマ」を押す | D-03 を開く（今の値に印） | T-15 |
| S-03「文字サイズ」を押す | D-04 を開く（今の値に印） | T-16 |
| D-03／D-04 の選択肢を押す | 印をその選択肢に移す（まだ保存しない） | - |
| D-03／D-04「OK」 | 印の値を保存して閉じる。アプリ全体にすぐ反映される | T-17 |
| D-03／D-04「キャンセル」／外を押す／戻る操作 | 何も変えずに閉じる | T-17 |
| S-03 ←／戻る操作 | 一覧へ戻る | T-18 |

- 画面を回転しても、開いたダイアログと選びかけの印は消えない
- アプリがシステムに終了された場合は、ダイアログは閉じた状態で設定画面に戻る（選びかけは残さない。保存済みの設定は残る）
- ダイアログが開いているときの戻る操作は、ダイアログを閉じるだけ（設定画面からは出ない）

## 5. 起動時の画面（スプラッシュ）（決定事項 2・3）

設定はファイルから読むので、起動直後の数十ミリ秒はまだ分からない。そのまま初期値（ライト・中）で描くと、ダークや「大」を選んでいる人には一瞬ライト・中が見えてから切り替わる（ちらつく）。そこで次のようにする。

1. 起動したらスプラッシュ画面（アプリのアイコンを中央に出した画面）を出す。Android 12 以降は OS が必ず出すもの。Android 10・11 でも同じ見た目で出す
2. **設定を読み終わるまで、かつ最低 0.5 秒はスプラッシュを出し続け**、両方を満たしたら、その設定で一覧を描く
3. スプラッシュは **0.2 秒かけてフェードアウト**して消す（パッと切り替わる感じを和らげるため）
4. 設定がまだ一度も保存されていない（初回起動）・ファイルが読めない場合は、初期値（ライト・中）で描く
5. → 7.4: 設定の読み込みが 3 秒たっても終わらないときは、待つのをやめて初期値で描く（8.1）

| 時間 | 値 | 考え方 |
|---|---|---|
| 最小表示時間 | 0.5 秒（アプリの画面を作り始めてから数える） | 読み込みが速くても「一瞬だけ見えて消える」感じを出さない。「起動から一覧の表示まで 2 秒以内」に十分収まる長さ |
| フェードアウト | 0.2 秒 | 長いと待たされる感じになるため短く |

- 最小表示時間は**新しく起動したときだけ**かける。画面の回転や、システムに終了されたあと画面ごと戻るとき（[下書き 基本設計](../下書き/基本設計.md)）は、0.5 秒待たずに設定を読み終わり次第描く（回転のたびに 0.5 秒何も出ない、とならないように）
- 下書きの復元で編集画面ごと戻るときも、設定を読み終わってから描く（最小表示時間はかけない）

| 項目 | 内容 |
|---|---|
| スプラッシュの背景 | 白（`#FFFFFF`、ライトの背景色）で固定 |
| スプラッシュのアイコン | ランチャーアイコンの前景（用紙と S）。背景の灰の円は付けない（[アイコン 基本設計](../アイコン/基本設計.md) 4 章） |

- 制限: スプラッシュは設定を読む前に OS が出すため、背景色を設定に合わせられない。ダークを選んでいる人は、起動の一瞬だけ白いスプラッシュが見えてからダークの一覧になる（中身のちらつきは出ない）。初期値がライトなので白に合わせた
- スプラッシュのアイコン: 最初は指定がなく Android 標準のアイコンだった → 2026-11-15 にランチャーアイコンの前景にした（アイコンを 6.4・6.5 で作ったため）

## 6. 設定の保存

| 設定 | 選べる値 | 初期値 |
|---|---|---|
| テーマ | 端末の設定に従う／ライト／ダーク | ライト |
| 文字サイズ | 小／中／大 | 中 |

- 「OK」を押した値は端末に保存し、アプリを閉じても、端末を再起動しても残る
- 保存した値が無い・読めない値（将来の版で増やした値を古い版で読んだ等）のときは、その項目だけ初期値にする（片方が壊れていても、もう片方は生かす）
- 保存先のファイルが壊れていて読めないときは、初期値で続ける（アプリを落とさない）。→ 7.4: 壊れたファイルは初期値で上書きし、「設定を初期値に戻しました」を一度だけ出す（8.3）
- 保存に失敗した場合は、表示も元の値のまま（エラー表示は出さない。まれなので割り切る）
- ~~設定は Android の自動バックアップの対象のまま（メモと同じ）~~ → 2026-11-17 の開発者の決定で、メモと同じく**バックアップしない**（[共通 基本設計](../共通/基本設計.md) 6.4）

## 8. 7.4 で変えるところ（Issue #59）

### 8.1 設定の読み込みが 3 秒を超えたとき（#59 決定 7）

5 章のとおり、起動時は設定を読み終わるまでスプラッシュを出し続ける。読み込みが終わらないと、スプラッシュのまま先へ進めない。

- 起動から **3 秒**たっても読み終わらなければ、**待つのをやめ、初期値（ライト・中）で一覧を開く**
- 一覧を開くときに「**設定を読み込めませんでした。初期値で表示します**」を数秒出す
- 読み込み自体は続ける（8.2）

設定の読み込みが遅れる・失敗する場面（7.4 の調べ）

| 場面 | 起きるか |
|---|---|
| 設定のデータが多い | **起きない**。設定は 2 項目・数十バイト |
| ファイルが壊れている | 起きうる → 8.3 |
| 記憶装置の一時的なエラー | 起きうる → 読み直す（8.4） |
| 端末が非常に重い（ほかのアプリで手一杯、記憶装置がとても遅い） | 起きうる → この 8.1 |

- 3 秒は「起動から一覧まで 2 秒以内」（非機能要件）より長い。ふだんは数十ミリ秒で読み終わるので、3 秒かかるのは異常のときだけ。異常のときは 2 秒の目安を守れなくてよい（開発者の決定）

### 8.2 3 秒を超えたあと、遅れて設定が読めたとき（#59 決定 10）

- **読めた値に切り替える**。開いている画面のまま、テーマと文字サイズが変わる（一度だけ見た目が変わる）
- 読めた値が初期値と同じなら、見た目は変わらない
- 8.1 のメッセージは取り消さない（出し終わっていなければ、そのまま消えるのを待つ）

### 8.3 設定のファイルが壊れていたとき（#59 決定 9）

- 壊れたファイルを**初期値で上書きする**。次に起動したときには、もう壊れていないので起きない
- 「**設定を初期値に戻しました**」を**一度だけ**出す（画面の回転などでもう一度出ない）
- テーマ・文字サイズは初期値（ライト・中）になる。ユーザーは設定画面で選び直せる
- 6 章の「保存した値が無い・読めない値」（ファイルは壊れていないが、中身の 1 項目が知らない値）は今までどおり、その項目だけ初期値にする。メッセージは出さない（ファイルは上書きしない）

### 8.4 一度読み込みに失敗しても、後の変更を反映する（#59 その他）

今の作りでは、読み込みが一度失敗すると初期値になったまま、そのあと「OK」で保存しても画面に反映されなかった（読み込みの流れが止まっていた）。7.4 からは:

- 壊れたファイル（8.3）以外の読み込みの失敗（記憶装置の一時的なエラー）は、少し待って**読み直す**。読めたら、その値に切り替える（8.2 と同じ）
- それ以外の読み込みの失敗（記憶装置のエラーでないもの。作りの間違いなど）でも**アプリを落とさない**。初期値（ライト・中）で開き、「設定を読み込めませんでした。初期値で表示します」を出す（3 秒の打ち切りと同じ知らせ。二重には出さない）。すでに読めていたときは、その値のまま知らせも出さない（開発者の決定（2026-11-17）。→ それまでは作りの間違いとして落としていた）
- 読み直している間に 3 秒たてば 8.1 のとおり初期値で開く
- そのあと「OK」で保存した値は、保存できればすぐに反映される

### 8.5 設定の保存が失敗したとき（#59 決定 1）

- 6 章のとおり、**表示は元の値のまま**、メッセージは出さない。**アプリは落とさない**（今は壊れたファイルのまま「OK」を押すと落ちていた）
- ダイアログは今までどおり「OK」ですぐ閉じる

### 8.6 メッセージの出し方（開発者の決定（2026-11-17））

8.1・8.3 のメッセージは、画面の下に数秒出る**トースト**（Android 標準の短い知らせ）で出す。

- 一覧の帯（Snackbar）でなくトーストにする理由: 設定はアプリ全体のもので、どの画面が開いていても（下書きの復元で編集画面から始まるときも）同じように出せるため。一覧の「＋」ボタンに重ならない
- 両方が起きたとき（壊れたファイルを直すのに 3 秒以上かかった）は、起きた順に 2 つ出す
