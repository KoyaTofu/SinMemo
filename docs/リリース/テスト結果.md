## 1. 8.1 ビルドの確認・自動テスト（2026-11-16）

本物の鍵は使わず、スクラッチパッドに**仮の鍵** 2 つを作って確かめた（確認後に削除）。

### 1.1 実行環境
クラウドのコンテナ（Linux、JDK 21）。build-tools 37.0.0 の `apksigner`・`aapt2`。

### 1.2 仮の鍵
```
$ keytool -genkeypair -keystore a.jks -storetype PKCS12 -keyalg RSA -keysize 2048 -validity 10000 \
    -alias sinmemo -dname "CN=SinMemo-test" ...     （パスワードは # $ \ 空白を含むもの）
$ keytool -genkeypair -keystore b.jks ... -alias other -dname "CN=SinMemo-test-env"
```

| ID | 結果 | 判定 |
|---|---|---|
